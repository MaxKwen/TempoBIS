# TempoBIS

**Motion-aware temporal normalization for speed-robust isolated BISINDO recognition**

TempoBIS recognizes a single Indonesian Sign Language (BISINDO) sign from video and asks one
focused question:

> How sensitive is a landmark-based BISINDO recognizer to changes in signing speed, and does
> placing timesteps by hand motion (instead of evenly in time) reduce that sensitivity?

Pipeline: video → MediaPipe pose + hand landmarks → per-frame features → fixed-length sequence
(uniform **or** motion-aware) → bidirectional GRU → gloss.

> **Status:** code complete and tested on synthetic data. Experiments on WL-BISINDO have not been
> run yet, so this README contains **no results**. Every number will come from
> `outputs/results/summary.md`, generated by the code.

## Dataset

[WL-BISINDO](https://github.com/AceKinnn/WL-BISINDO): word-level BISINDO videos (Banten variant),
32 glosses, 5 signers, about 1,600 videos, published with Kindy, Leonali & Lucky (2025),
*Procedia Computer Science* 269, 249–258, [doi:10.1016/j.procs.2025.08.277](https://doi.org/10.1016/j.procs.2025.08.277).
License **CC BY-NC 4.0**. The videos are **not** included in this repository. Download them from
Kaggle (link in the WL-BISINDO repo). Exact counts are verified by `python -m tempobis audit`.

## Method in one picture

```
hand motion energy  ▁▁▁▂▆█▇▅▄▅▆▅▃▂▁▁▁
uniform timesteps   |  |  |  |  |  |  |  |  |  |     evenly spaced in time
motion-aware        |    |   ||||||||||||   |    |   denser where the hands move
```

* **Uniform (baseline):** T evenly spaced positions over the whole clip, by linear interpolation.
* **Trim + uniform (ablation):** cut the low-motion head/tail, then uniform.
* **Motion-aware (proposed):** positions follow the inverse cumulative distribution of
  `(1 − α) · motion density + α · uniform density`. With α = 1 it is exactly the baseline.
* **Uniform + speed augmentation (comparator):** the baseline trained on randomly sped-up/slowed-down
  copies. This is the obvious alternative to a smarter normalization, so it is reported too.

Details, design decisions and known risks: [docs/methodology.md](docs/methodology.md).

## Speed stress test

Models are trained on unmodified data and tested on the held-out signer at speed factors
0.5×–1.5×, with two perturbations applied to the landmark sequence:

| Perturbation | What changes | Why |
|---|---|---|
| `global` | whole clip plays s× faster | sanity check: uniform resampling should largely absorb this |
| `core` | only the signing segment (hands raised) changes speed; idle head/tail stay the same | closer to a signer who signs faster but pauses the same; this is where uniform sampling can shift |

The signing segment is located from **wrist height**, not from motion energy, so the perturbation
is not defined by the same signal the proposed method uses.

## Reproduce

Everything runs in one Kaggle notebook: [`notebooks/tempobis_kaggle.ipynb`](notebooks/tempobis_kaggle.ipynb)
(add the WL-BISINDO dataset, turn Internet on, run the sections in order).

Or from a terminal:

```bash
pip install -e ".[gru,dev]"
python -m pytest                                      # unit + end-to-end tests (synthetic data)
python -m tempobis smoke                              # whole pipeline on synthetic data, ~30 s

# real data (set paths.video_root in a copy of configs/default.yaml if not on Kaggle)
python -m tempobis audit   --config configs/default.yaml   # Phase 0
python -m tempobis pilot   --config configs/default.yaml   # Phase 1: 10 videos
python -m tempobis extract --config configs/default.yaml   # Phase 2
python -m tempobis train   --config configs/default.yaml   # Phases 3–5 (+ report)
python -m tempobis analyze --config configs/default.yaml   # Phase 6
```

Protocol: leave-one-signer-out (5 folds) × 3 seeds; validation = stratified 15% of the training
signers; the held-out signer is never used for model selection. All methods share the split,
features, model and seed, so only the temporal normalization differs. The official WL-BISINDO
signer-independent split (test signer 4) is available as `split.protocol: si_signer4`.

## Limitations

* Speed changes are synthetic (interpolated landmark sequences). Natural speed variation between
  signers also changes hand shape and movement form, which this test does not capture.
* 32 glosses, 5 signers, one regional variant (Banten): results do not transfer to BISINDO as a whole.
* Landmark-only input: facial expression and mouthing, which carry meaning in BISINDO, are not used.
* Motion energy also peaks on raise/lower transitions, which are not part of the sign itself; the
  α blend limits this, and the ablation shows how much it matters.
